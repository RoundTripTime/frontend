## 성공 지표

### 비즈니스 지표

- 주간 활성 계획 사용자 수
- 링크 → 계획 생성 전환율
- 저장된 계획 재사용률
- 최소 1개 계획 생성 사용자의 30일 유지율
- **OTA 전환율** (일정 → OTA 예약 클릭 비율)
- **OTA 수수료 수익**

### 제품 지표

- 후보 확인율
- 소스당 확정 장소 수 평균
- 추출 후 수동 수정률
- 링크 제출 → 사용 가능한 일정까지 소요 시간

### 기술 지표

- LLM 파싱 비용 / OCR·VLM 처리 비용
- 지도 정규화 정밀도
- 푸시 알림 전달 성공률

## MVP 정의

- iOS / Android 공유하기 링크 수신
- Search Console 색인 기반 경로 분기
- [색인 O] Cloud LLM 장소 파싱
- [색인 X] OCR / VLM 장소 추출
- 지도 정규화
- 사용자 확인 UI
- 일정 초안 생성 및 저장

> 웹 버전은 장소 추출 기능을 제공하지 않는다.
>

## 출시 로드맵

### Phase 0 — 기반

- 인증, 사용자 프로필, 푸시 인프라
- 링크 수집 및 출처 분류

### Phase 1 — 추출

- Search Console 색인 체크 구현
- Cloud LLM 파싱 경로 구현
- OCR / VLM 파이프라인 구현
- 지도 정규화 및 후보 랭킹

### Phase 2 — 공유 및 재사용

- 판매 및 공유 가능한 계획
- **Planning Agent**
    - 자연어 기반 일정 대화형 편집
    - 유사 장소 추청 (pgvector 임베딩 검색)
    - 동선 최적화 요청 처리
- 숙소 및 비행기 제휴 OTA

### Phase 3 — 웹

- 일정 조회, 편집, 공유 (장소 추출 기능 제외)
