# Problem & Users

## 문제 정의

여행 발견과 여행 계획 수립은 현재 단절된 워크플로우이다.

### 사용자 불편 사항

1. 사용자는 숏폼 영상과 블로그에서 여행지를 발견하지만 이를 실행 가능한 계획으로 전환하기 어렵다.
2. 유의미한 정보가 캡션, 자막, 해시태그, 간판, 외부 지도 등 여러 위치에 분산되어 있다.
3. 사용자는 메모, 채팅, 스프레드시트, 지도 리스트 등에 수작업으로 계획을 다시 정리해야 한다.
4. 한 번 만든 여행 계획도 비정형 데이터이기 때문에 재사용 가치가 낮다.

### 기존 도구의 한계

- **북마크 도구**: 링크를 저장할 뿐, 여행 의도를 구조화하지 못한다.
- **지도 리스트**: 직접 입력이 필요하며 크리에이터 맥락을 잃는다.
- **일반 여행 플래너**: 사용자가 이미 장소를 알고 있다고 가정한다.
- **소셜 앱**: 소비 경험에 최적화되어 있고 여행 계획 전환에는 최적화되어 있지 않다.

## 목표와 비목표

### 제품 목표

1. iOS, Android 앱에서 공유하기 기능을 통해 소셜 및 지도 링크를 수집할 수 있어야 한다. (웹은 MVP 이후 지원)
2. 사용자가 공유하기로 앱에 링크를 전달하면, Google Search Console 색인 여부를 먼저 확인해야 한다. 색인된 경우 클라우드 LLM을 호출해 장소를 파싱하고, 색인되지 않은 경우 OCR 및 VLM 파이프라인으로 전환한다.
3. 지도 공급자 기준으로 후보를 정규화해 구조화된 위치 엔티티를 생성해야 한다.
4. 사용자는 비동기 분석 흐름 안에서 최소한의 마찰로 결과를 받아야 한다.
5. 확정된 장소를 기반으로 공유 가능한 여행 일정을 생성해야 한다.
6. 완성된 일정에서 OTA(Online Travel Agency)로 이동해 숙소·항공·액티비티를 예약할 수 있어야 한다.
7. OTA 예약 연결을 통해 수수료 수익을 창출해야 한다.
8. 여행 계획을 단발성으로 소비하는 것이 아닌 재사용 가능한 마켓플레이스를 구축해야 한다.

### MVP 비목표

1. 사용자 확인 없이 100% 자동으로 장소를 완벽 식별하는 것
2. 원시 프레임, 원시 오디오, 원본 비디오의 장기 저장
3. 크리에이터 미디어 호스팅 또는 앱 내 영상 재생
4. 실시간 협업 일정 편집
5. 웹 버전 (MVP 이후 단계에서 지원)

### Jobs To Be Done

- 여행 영상을 발견했을 때 수기로 메모하지 않고 장소를 저장하고 싶다.
- 여행을 계획할 때 관련 장소들이 지도 기준으로 정리되어 있기를 원한다.
- 분석이 모호하면 처음부터 다시 입력하는 대신 빠르게 후보만 확인하고 싶다.
- 진행중인/완성된 계획을 공유하고 싶다.
- 계획을 다 세우고 나서 앱 안에서 바로 숙소·항공을 예약하고 싶다.
