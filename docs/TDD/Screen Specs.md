## S-01 · 온보딩

**목적** 앱의 핵심 가치를 설명하고 소셜 로그인으로 가입을 유도한다.

**구성 요소**

- 슬라이드 3장 (여행 영감 저장 → 장소 자동 추출 → 일정 생성 및 예약)
- 소셜 로그인 버튼 (Google, Kakao)

**동작**

- 로그인 성공 시 S-02로 이동

---

## S-02 · 홈 (내 장소)

**목적** 내가 저장한 장소를 플레이스별로 탐색하고 관리하는 기본 화면. 홈과 플레이스를 통합한 단일 진입점.

**구성 요소**

- 상단 탭: **전체** · **일본** · **한국** · **동남아** 등 (앱 자동 분류 기반, 사용자 변경 가능)
- 장소 카드 그리드
    - 장소 썸네일 / 장소명 / 카테고리 / 국가
- 플레이스 추가 버튼 (+ 아이콘, 우상단)
- 하단 탭: **홈** · **플랜** · **둘러보기** · **설정**

**동작**

- 탭 전환 → 해당 플레이스 장소 필터링
- 장소 카드 탭 → S-05 장소 상세
- 장소 롱프레스 → 다른 플레이스로 이동 / 삭제
- 플레이스 추가 버튼 → 이름 입력 시트
- 플레이스 우상단 공유 버튼 → 공개 URL 생성 (비로그인 열람 가능)
- **홈 진입 시**: 최근에 장소가 추가된 경우 하단 토스트 자동 표시
    - 토스트 문구: "📍 도쿄 맛집 VLOG에서 장소 3곳이 추가됐어요"
    - 토스트 탭 → S-04 최근 추가한 장소 이동
    - 토스트는 3초 후 자동 사라짐, 미확인 시 다음 진입 때 재표시

> 비로그인 사용자는 공유된 플레이스·플랜 링크에 한해 열람 가능.
> 

**데이터**

- 플레이스는 사용자 정의. 이름과 아이콘 커스터마이즈 가능.
- 앱이 장소의 지역·카테고리 정보를 기반으로 자동 분류. 사용자가 원하면 변경 가능.
- 장소는 여러 플레이스에 동시에 속할 수 있음.

## S-03 · 링크 수신 (분석 중)

**목적** 앱 선택 즉시 분석이 시작됨을 알리고, 앱으로 돌아가도 된다는 안내를 제공한다.

**구성 요소**

- 수신된 링크 미리보기 (URL + 플랫폼 아이콘 + 썸네일)
- 진행 인디케이터 (로딩 애니메이션)
- 안내 문구: "장소를 찾고 있어요. 잠시 후 알려드릴게요."
- 하단: "앱으로 돌아가기" 텍스트 링크 (버튼 아님)

**동작**

- 앱 선택 즉시 백그라운드 분석 잡 자동 생성 — 별도 버튼 없음
- 1~2초 후 자동으로 홈(S-02)으로 복귀
- 분석 완료 시 푸시 알림 전송
- 홈(S-02) 진입 시 토스트로 결과 알림 → 탭 시 S-04 이동

**제약**

- iOS: Share Extension
- Android: Share Intent
- 확인/취소 버튼 없음. 공유하기로 앱 선택 자체가 트리거

## S-04 · 최근 추가한 장소

**목적** 분석이 완료되어 새로 추가된 장소를 확인하고 플레이스 또는 플랜에 배치한다.

**구성 요소**

- 상단: 분석 출처 링크 정보 (플랫폼 아이콘 + URL + 제목)
- 장소 카드 리스트
    - 장소 썸네일 / 장소명 / 카테고리 / 국가
    - 수락 · 거절 버튼
- 하단 액션
    - **플레이스에 추가** → 수락된 장소를 특정 플레이스에 저장
    - **플랜에 추가** → 수락된 장소를 특정 플랜에 추가 (S-07)

**동작**

- 진입 경로: S-02 홈 토스트 탭 / 푸시 알림 탭
- 장소 카드 탭 → S-05 장소 상세
- 거절 → 해당 카드 제거
- 전체 처리 완료 후 → 홈(S-02)으로 복귀

## S-05 · 장소 상세

**목적** 특정 장소의 정규화된 정보와 지도를 확인하고, 원본 영상으로 이동해 내용을 재확인한 뒤 수락 / 거절을 결정한다.

**구성 요소**

- 지도 (전체 너비)
- 장소명 / 카테고리 / 주소
- 외부 지도 앱 연결 버튼 (Kakao / Google Maps)
- **원본 영상 섹션**
    - 플랫폼 아이콘 + 제목 + 썸네일
    - '영상 보러 가기' 버튼 → 원본 플랫폼(YouTube, Instagram 등) 앱 또는 웹으로 이동
    - 플랫폼별 처리: YouTube는 딥링크 우선, 앱 미설치 시 웹 폴백 / Instagram 동일
- 추출 근거 섹션 (이 영상의 어떤 부분에서 장소가 추출됐는지)
- 수락 / 거절 버튼

**제약**

- 원본 영상을 앱 내에서 재생하지 않는다. (No Forced Replay 원칙)
- 썸네일은 `source_links` 테이블의 메타데이터에서 가져온다. 별도 영상 저장 없음.

## S-06 · 플랜 목록

**목적** 진행 중이거나 완성된 여행 플랜을 관리하는 허브 화면.

**구성 요소**

- 플랜 카드 리스트
    - 여행지 / 기간 / 인원 / 상태 (`초안` · `확정` · `완료`)
    - 공유 상태 배지 (`공개` · `비공개`)
- '새 플랜 만들기' 버튼

**동작**

- 플랜 카드 탭 → S-07 이동
- '새 플랜 만들기' → 기본 정보 입력 시트 (여행지, 날짜, 인원) → S-07 생성

## S-06N · 새 플랜 만들기

**목적** 2단계 플로우로 플랜의 기본 정보와 초기 장소를 설정한 뒤 편집 화면으로 진입한다.

---

### Step 1 — 기본 정보

**구성 요소**

- 상단 스텝 인디케이터 (● ○)
- **플랜 이름** 텍스트 필드 (예: "도쿄 여름 여행", 최대 50자)
- **여행지**
    - 퀵 칩: 일본 · 한국 · 태국 · 베트남 · 기타 (탭 시 선택, 중복 선택 불가)
    - 직접 입력 텍스트 필드 (퀵 칩 선택 시 자동 채워짐, 덮어쓰기 가능)
- **날짜 범위** 날짜 선택기 (출발일 ~ 도착일, 캘린더 인라인 표시)
- **인원** ± 버튼 (1~20명, 기본값 1)
- 하단 **다음** 버튼

**동작**

- 플랜 이름, 여행지, 날짜 모두 입력 전까지 **다음** 버튼 비활성화
- 날짜 도착일 < 출발일 선택 불가 (캘린더에서 비활성 처리)
- **다음** 탭 → Step 2로 전환

---

### Step 2 — 장소 선택

**구성 요소**

- 상단 스텝 인디케이터 (● ●)
- 상단 뒤로가기 버튼 → Step 1으로 복귀 (입력 값 유지)
- **전체 선택 / 해제** 체크박스 (목록 최상단)
- 내 저장 장소 리스트
    - 장소 카드: 썸네일 · 장소명 · 카테고리 · 국가
    - 카드 우측 체크박스 (다중 선택)
- 저장 장소 없을 경우: "아직 저장한 장소가 없어요. 건너뛰고 나중에 추가할 수 있어요." 안내 + 건너뛰기 버튼
- 하단 **플랜 만들기** 버튼 (선택한 장소 수 표시, 예: "플랜 만들기 · 3개 선택됨")

**동작**

- 장소 미선택 상태에서도 **플랜 만들기** 버튼 활성화 (장소 없이 생성 가능)
- 전체 선택 체크박스 탭 → 전체 선택 / 전체 해제 토글
- **플랜 만들기** 탭 → `POST /itineraries` 호출 후 선택 장소 일괄 추가 → S-07 플랜 상세/편집으로 이동

---

**유효성 규칙 요약**

| 항목 | 조건 | 처리 |
| --- | --- | --- |
| 플랜 이름 | 공백·미입력 | 다음 버튼 비활성화 |
| 여행지 | 미선택·미입력 | 다음 버튼 비활성화 |
| 날짜 범위 | 미선택 | 다음 버튼 비활성화 |
| 날짜 범위 | 도착일 < 출발일 | 캘린더에서 선택 불가 처리 |
| 인원 | 1 미만 |   • 버튼 비활성화 |

## S-07 · 플랜 상세 / 편집

**목적** 여행 날짜·인원을 설정하고, 장소를 일자별로 배치하며, 예약으로 발전시킨다.

**구성 요소**

- 플랜 기본 정보
    - 여행지 / 출발~도착 날짜 / 인원 수
- 일자별 섹션 (Day 1 · Day 2 · …)
    - 장소 카드 (드래그로 순서 변경)
    - 장소 간 예상 이동 시간
- 장소 추가 버튼
    - 홈(내 장소)에서 가져오기
    - 직접 검색
- 일자 미지정 장소 풀 (Day 미배치 상태로 추가 가능, 이후 드래그로 배치)
- **Agent 버튼** — Planning Agent 대화창 열기 (S-08)
- **지도 버튼** (S-07-M 지도 스플릿 뷰 진입) — 플랜 장소 전체를 지도로 조망
- **공유 버튼** (상단 우측)
    - 공개 URL 생성 → 링크 복사 / SNS 공유
    - 공유 시 노출 범위: 장소 목록 + 일정 + OTA 예약 버튼 (편집 불가)
    - 공개 / 비공개 전환 가능
- **OTA 예약 섹션** (하단 고정)
    - 숙소 예약 → 제휴 OTA로 이동 (날짜·인원·지역 파라미터 자동 전달)
    - 항공 예약 → 제휴 OTA로 이동
    - 액티비티 예약 (Phase 이후 확장)
- '저장' 버튼

**동작**

- 드래그 앤 드롭으로 장소 순서 / 날짜 변경
- OTA 버튼 탭 → 외부 OTA 앱 또는 웹으로 이동 (어필리에이트 링크)
- '저장' → S-09 이동

## S-08 · Planning Agent 대화

**목적** 자연어로 플랜을 수정하거나 유사 장소를 추천받는다.

**구성 요소**

- 대화 메시지 리스트 (채팅 UI)
- 텍스트 입력창
- 빠른 제안 칩 (예: "동선 최적화해줘", "비슷한 카페 찾아줘", "2일차 비워줘")
- Agent 응답 카드
    - 추천 장소 목록 (수락 / 거절 인라인)
    - 재배열 결과 미리보기
- '플랜에 반영' 버튼 (Agent 제안 수락 시 활성화)

**동작**

- 사용자 입력 → Agent Tool 실행 → 결과 카드 반환
- '플랜에 반영' → S-07 업데이트 후 대화창 닫기
- 대화 히스토리는 해당 플랜 세션 동안 유지 (앱 재시작 시 초기화)

## S-09 · 플랜 공유 / 상세

**목적** 완성된 플랜을 확인하고 공유하거나 OTA에서 예약한다.

**구성 요소**

- 플랜 요약 (제목 / 기간 / 인원 / 장소 수)
- 일자별 장소 리스트 (읽기 전용)
- 지도 전체 보기
- 공유 버튼 → 링크 복사 / SNS 공유
- '편집' 버튼 → S-07 이동

**동작**

- 공유 링크는 비로그인 사용자도 조회 가능한 공개 URL 생성

## S-07-M · 플랜 지도 스플릿 뷰

**목적** 플랜의 장소들을 지도 전체화면으로 조망하면서, 하단 시트로 일정을 동시에 확인한다.

**진입 경로** S-07 플랜 상세/편집 우상단 지도 버튼 탭

**구성 요소**

- 전체화면 지도 (장소 마커 표시, Day별 색상 구분)
- 하단 스플릿 시트 (드래그로 높이 조절 가능)
    - 접힌 상태(기본): 장소명 + Day 배지 가로 스크롤 칩
    - 반 펼친 상태: Day별 장소 카드 리스트
    - 완전 펼침: 전체 일정 (S-07과 동일)
- 상단 좌측 닫기(X) 버튼 → S-07로 복귀
- 장소 마커 탭 → 해당 장소 정보 말풍선 표시 (장소명 / 카테고리 / Day 배지)

**동작**

- 지도 진입 시 플랜 내 모든 장소 마커 자동 표시
- Day 1 · Day 2 · … 마커 색상 구분 (Primary Orange 계열 음영)
- 미배치 장소는 회색 마커로 표시
- 마커 탭 → 말풍선 팝업, 팝업 탭 → S-05 장소 상세
- 하단 시트 드래그 업 → 일정 상세 노출, 드래그 다운 → 지도 영역 확대

## S-11 · 커뮤니티

**목적** 플레이스·플랜을 태그하고 공유하며 다른 여행자들과 소통하는 공간. **플랜 마켓** 탭을 포함.

**구성 요소**

- 포스트 카드 리스트 (전체 / 팔로잉 탭)

    - 좋아요 수 / 댓글 수
    - 좋아요 버튼 / 댓글 버튼
- 포스트 작성 FAB (전체 / 팔로잉 탭에서만 노출)
- 하단 탭: **홈** · **플랜** · **커뮤니티** · **둘러보기** · **설정**

**포스트 작성 시트**

- 텍스트 입력

- 공개 범위: 전체 공개 / 팔로워만

**동작**

- 피드 탭 전환 → `GET /community/posts?feed=all|following`
- **플랜 마켓 탭** → S-11M 플랜 마켓 목록으로 이동
- 좋아요 → `POST /community/posts/:id/like`
- 댓글 → `GET /community/posts/:id/comments` + 입력창
- 태그된 플레이스 탭 → S-05 장소 상세 이동
- 태그된 플랜 탭 → S-09 플랜 공유/상세 이동
- 포스트 작성 FAB → 작성 시트

## S-11M · 플랜 마켓 목록

**목적** 다른 사용자가 실제 여행 후 등록한 플랜을 탐색하고, 크레딧으로 열람한다.

**진입 경로** S-11 커뮤니티 상단 **플랜 마켓** 탭 탭

**구성 요소**

- 상단 헤더
    - "플랜 마켓" 타이틀
    - 우상단 크레딧 잔액 배지 (예: 💎 3) — 탭 시 크레딧 내역 시트
- 필터 칩
    - 국가 (전체 / 일본 / 한국 / 동남아 등)
    - 정렬 (최신순 / 인기순)
- 플랜 카드 리스트
    - 대표 썸네일 (플랜 내 첫 번째 장소 이미지)
    - 여행지 / 기간 (N박 N일) / 인원
    - 작성자 닉네임 + 아바타
    - 한 줄 소개 (`highlight`)
    - 포함 장소 수 · 조회수
    - OTA 예약 완료 뱃지 (✈️ 실제 다녀온 플랜)
    - 크레딧 가격 배지 (💎 1)
- 우하단 FAB: 내 플랜 등록하기 → S-11MR 플랜 마켓 등록

**동작**

- 진입 시 `GET /market/plans` 호출
- 국가 / 정렬 필터 탭 → 파라미터 변경 후 재호출
- 플랜 카드 탭 → S-11MP 플랜 마켓 상세 (미리보기)
- 크레딧 배지 탭 → 크레딧 내역 바텀 시트
- FAB 탭 → S-11MR 플랜 마켓 등록
- 스크롤 하단 → cursor 기반 다음 페이지 로드

## S-11MP · 플랜 마켓 상세 (미리보기 / 열람)

**목적** 플랜 마켓에 등록된 플랜의 미리보기를 보고, 크레딧을 사용해 전체 일정을 열람한다.

**진입 경로** S-11M 플랜 마켓 목록에서 카드 탭

**구성 요소**

**[잠금 상태 — 크레딧 미사용]**

- 플랜 기본 정보 (여행지 / 기간 / 인원 / 작성자)
- OTA 예약 완료 뱃지 (✈️ 실제 다녀온 플랜 인증)
- 한 줄 소개 (`highlight`)
- 소개 텍스트 (`description`) 전체 노출
- 미리보기 장소 카드 1개 (썸네일 + 장소명, `preview_places`)d
- 잠금 블러 영역: "+ N개 장소가 숨겨져 있어요" 블러 오버레이
- **크레딧으로 열기 버튼** (💎 1 크레딧)
    - 크레딧 있음: 즉시 열람 확인 다이얼로그
    - 크레딧 부족: "광고 보고 크레딧 충전하기" 시트 자동 표시

**[열람 상태 — 크레딧 사용 후 or 이미 구매]**

- 플랜 기본 정보 (여행지 / 기간 / 인원 / 작성자)
- 소개 (`description`) / 좋았던 점 (`pros`) / 아쉬웠던 점 (`cons`) / 팁 (`tips`)
- Day별 전체 일정
    - 각 일자별 장소 카드 (썸네일 + 장소명 + 카테고리 + 예상 체류시간)
    - 장소 탭 → S-05 장소 상세
- **내 플랜으로 복사하기** 버튼 → 해당 플랜을 내 플랜으로 복제 후 S-07 편집 화면으로 이동

**동작**

- 진입 시 `GET /market/plans/:id/preview` 호출 (무료)
- 크레딧으로 열기 탭 → 확인 다이얼로그 → `GET /market/plans/:id` 호출 (크레딧 차감)
- 크레딧 부족 시 → 광고 시청 바텀 시트 표시 (S-11MAD)
- 내 플랜으로 복사하기 → `POST /itineraries` (복제) 후 S-07 이동

## S-11MAD · 광고 시청 (크레딧 충전)

**목적** 광고 5회 시청 시 크레딧 1개를 적립한다. 크레딧 부족 시 자동으로 진입.

**진입 경로** S-11MP에서 크레딧 부족 시 / 크레딧 배지 탭 후 충전 버튼 탭

**구성 요소**

- 바텀 시트 형태 (모달)
- 현재 크레딧 잔액 표시 (💎 N)
- 광고 시청 진행 상태 (예: 3/5 시청 완료)
- 진행 바 (5칸 중 N칸 채워짐)
- "광고 보기" 버튼
- 안내 문구: "광고 5개를 보면 플랜 1개를 열어볼 수 있어요"
- 닫기 버튼

**동작**

- "광고 보기" 탭 → `POST /credits/ads/start` → 광고 재생
- 광고 완료 → `POST /credits/ads/complete` 호출
- `viewed_today` 5 도달 시 크레딧 1 자동 적립 + 잔액 업데이트 + 완료 토스트 표시
- 크레딧 적립 완료 시 시트 닫고 S-11MP로 복귀 (자동 열람 가능 상태)

## S-11MR · 플랜 마켓 등록

**목적** OTA 예약이 완료된 내 플랜을 마켓에 등록하고 크레딧을 받는다.

**진입 경로** S-11M 플랜 마켓 목록 FAB 탭

**구성 요소**

- 등록 가능한 플랜 선택 리스트
    - OTA 예약 완료 플랜만 노출 (✈️ 뱃지)
    - 이미 등록된 플랜은 비활성화
    - 플랜 없을 경우: "OTA로 예약한 플랜이 있어야 등록할 수 있어요" 안내
- 플랜 선택 후 입력 폼
    - 제목 (최대 50자, 필수)
    - 한 줄 소개 `highlight` (최대 100자, 필수)
    - 소개 `description` (최대 500자, 필수)
    - 좋았던 점 `pros` (최대 300자, 필수)
    - 아쉬웠던 점 `cons` (최대 300자, 필수)
    - 추가 팁 `tips` (최대 300자, 선택)
- 등록 완료 버튼

**동작**

- 플랜 선택 → 폼 입력 화면 전환
- 등록 완료 탭 → `POST /market/plans` 호출
- 성공 시 토스트 "플랜이 마켓에 등록됐어요! 다른 여행자가 열람할 때 크레딧이 적립돼요" + S-11M으로 복귀
- OTA 미예약 플랜 선택 불가 → 안내 메시지 표시

## S-11A · 커뮤니티 포스트 상세

**목적** 커뮤니티 피드의 특정 포스트를 자세히 보고, 댓글을 읽거나 작성한다.

**진입 경로** S-11 커뮤니티 피드에서 포스트 카드 탭

**구성 요소**

- 상단 네비게이션 바
    - 뒤로가기 버튼
    - 더보기 버튼 (신고 / 차단 / 공유)
- 포스트 본문 영역
    - 작성자 프로필 (아바타 + 닉네임 + 작성 시간)
    - 팔로우 버튼 (비팔로우 상태일 때)
    - 본문 텍스트
    - 태그된 플레이스 / 플랜 카드 (썸네일 + 이름, 탭 시 상세로 이동)
    - 좋아요 수 / 댓글 수
    - 좋아요 버튼 / 공유 버튼
- 구분선
- 댓글 목록
    - 댓글 카드: 작성자 아바타 + 닉네임 + 내용 + 작성 시간
    - 댓글 롱프레스 → 삭제 (본인 댓글만)
- 하단 댓글 입력창 (고정)
    - 텍스트 입력 필드
    - 전송 버튼

**동작**

- 진입 시 `GET /community/posts/:id` + `GET /community/posts/:id/comments` 호출
- 좋아요 버튼 탭 → `POST /community/posts/:id/like` (토글)
- 댓글 전송 → `POST /community/posts/:id/comments`
- 태그된 플레이스 탭 → S-05 장소 상세
- 태그된 플랜 탭 → S-09 플랜 공유/상세
- 팔로우 버튼 탭 → `POST /users/:user_id/follow`

## S-10 · 둘러보기

**목적** 사용자가 최근 저장한 장소 데이터를 기반으로 유사한 장소를 추천한다. 여행 영감을 지속적으로 발견하는 탐색 공간.

**구성 요소**

- 카테고리 필터 칩 (전체 / 관광명소 / 맛집 / 카페 / 숙박 등)
- 국가 필터 칩 (전체 / 한국 / 일본 / 동남아 등)
- 장소 카드 그리드
    - 장소 썸네일 (Flickr → Wikimedia → Google Places Photos 폴백 순)
    - 장소명 / 카테고리 / 국가
    - 저장 버튼
- 하단 탭: **홈** · **플랜** · **둘러보기** · **설정**

**동작**

- 진입 시 `GET /discover` 호출 → 취향 기반 장소 추천 목록 표시
- 카테고리 / 국가 필터 탭 → 필터 파라미터 변경 후 재호출
- 장소 카드 탭 → S-05 장소 상세 이동
- 저장 버튼 탭 → 장소를 홈(내 장소)에 추가, 썸네일 캐싱 트리거
- 스크롤 하단 도달 → 다음 페이지 로드 (cursor 기반 페이지네이션)

**콜드 스타트 처리**

- 저장 장소 3개 이하: 개인화 추천 대신 카테고리 인기순 fallback 표시
- fallback 상태에서는 "지금 인기있는 장소" 레이블 표시

**썸네일 폴백 전략**

1. Flickr API (좌표 기반 CC 라이선스 사진, 무료)
2. Wikimedia Commons geosearch (랜드마크·관광명소 특화, 무료)
3. Google Places Photos (저장 시 1회 호출 후 캐싱, 건당 $0.007)

## S-12 · 설정

**목적** 계정 정보와 앱 환경설정을 관리한다.

**구성 요소**

- 프로필 섹션
    - 프로필 사진 (기본: 형용사+동물+숫자 조합 기반 자동 생성 아바타, 예: "이상한 여우 8237")
    - 닉네임 (기본: "이상한 여우 8237" 형식 자동 부여)
    - 프로필 섹션 탭 → S-12-P 프로필 수정 화면으로 이동
- 계정 정보 (이메일)
- 알림 설정
- 지도 공급자 선호 설정 (Kakao / Google)
- 로그아웃 / 계정 삭제

**닉네임 생성 규칙**

- 형식: `형용사 + 동물명 + 4자리 숫자` (예: 이상한 여우 8237, 용감한 고래 1042)
- 가입 시 서버에서 랜덤 생성, 중복 허용
- 사용자가 언제든 변경 가능 (중복 허용, 길이 제한 20자)

**기본 아바타 생성 규칙**

- 닉네임의 동물을 기반으로 일러스트 스타일 아바타 자동 생성
- 사용자가 갤러리 사진으로 교체 가능, 기본 아바타로 되돌리기 가능

## S-12-P · 프로필 수정

**목적** 설정 화면에서 분리된 프로필 수정 플로우로 닉네임과 프로필 이미지를 변경한다.

**구성 요소**

- 프로필 미리보기
    - 프로필 이미지
    - 닉네임
    - 이메일
- 닉네임 입력
- 프로필 이미지 URL 입력
- 저장 버튼

**동작**

- 저장 버튼 탭 → `PATCH /users/me`
- 요청 필드
    - `nickname`
    - `avatar_url`
- 저장 성공 시 변경된 사용자 객체를 현재 세션에 반영하고 S-12로 돌아간다.
 
**네비게이션**

- 가능한 다음 이동 화면: 없음
